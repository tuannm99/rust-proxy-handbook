# milestone-01-echo

Milestone 1 from the handbook: a TCP echo server on tokio. This is a
learning stage, not a deliverable — it builds toward `proxy/`, the actual
finished proxy.

Handbook references:
- `instruction/10-projects/project-01.md` — goal and scope
- `instruction/01-network/socket.md`, `instruction/01-network/tcp.md`
- `instruction/03-rust/async.md`, `instruction/04-runtime/tokio.md`

Run with:

```
cargo run -p milestone-01-echo
```
