# Reference

Appendix material — quick lookup, not a learning path. Cross-referenced
from other topic files rather than read start-to-end.

## Status: index only — not written, and best written by you

Nothing here is written yet and nothing links to it. That is less of a gap
than it looks: a glossary and cheatsheet are lookup aids, and the version
that helps is the one written in your own words as you hit each term.

When to come back: continuously, as a byproduct. Every time you have to
look up an `errno`, a status code, or what "head-of-line blocking" means in
the HTTP/2 sense versus the TCP sense, add the line here. Writing this
folder up front, before the terms have cost you anything, produces a
glossary you will never open.
